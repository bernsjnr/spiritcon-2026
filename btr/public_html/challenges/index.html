How it works

Four steps, no forms

  1. Join the club

    Join BTR on Strava. It's free and takes a tap.

  2. Join the challenge

    Hit the button on a challenge card to join it on Strava.

  3. Run

    Record runs on Strava as normal. Any pace, any route, solo or with us.

  4. Check back

    When it closes we check results and post the winners here.
